# InventarioArvores

Projeto Web do Inventário de Árvores do município para consulta das informações das árvores pela população através de um QR Code [Prefeitura Municipal de Vinhedo](https://www.vinhedo.sp.gov.br) desenvolvido como parte do Projeto Integrador II da UNIVESP.

### Disciplina
Projeto Integrador em Computação II. Eixo de Computação. UNIVESP - Universidade Virtual do Estado de São Paulo

## Motivação
O Projeto Integrador trata de resolução de problemas e os estudantes devem ser expostos a atividades que visam relacionar conteúdos curriculares a práticas profissionais. Cada Projeto Integrador é estruturado para consolidar o conhecimento das disciplinas dos semestres anteriores em atividades práticas que visam buscar a solução para um problema e sua implementação. O objetivo é se chegar a um protótipo funcional que sirva como prova de conceito das ideias propostas. 

## Definição
Inventário de árvores e consulta por QR Code através de um sistema web (HTML, CSS, Javascript) com API contendo banco de dados, controle de versão e testes do código-fonte hospedado na nuvem e com recursos de acessibilidade 

### Características
- Gerenciador de Espécies
- Gerenciador de Árvores

## Tecnologias
.NET 9, ASP.NET Core Web API, Swagger, Angular, MongoDB, Azure, EF Core e Identity Api Endpoints
